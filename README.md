# Norte Tech

Sitio web oficial y catálogo digital de Norte Tech.

## Descripción

Aplicación web desarrollada en React y Vite con catálogo de productos, carrito de compras e integración con Mercado Pago para pagos en línea y pedidos vía WhatsApp.

## Tecnologías utilizadas

- **Frontend:** React 18, Vite, CSS3
- **Backend / Serverless:** Vercel Serverless Functions (`api/`)
- **Integraciones:** Mercado Pago Checkout Pro

## Instalación y Desarrollo

1. Clona el repositorio e instala las dependencias:
   ```bash
   npm install
   ```

2. Inicia el servidor de desarrollo local:
   ```bash
   npm run dev
   ```

3. Construye el proyecto para producción:
   ```bash
   npm run build
   ```
